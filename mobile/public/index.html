Cookie Setup Guide:

  1. Install browser extension: Get cookies.txt LOCALLY (Chrome/Firefox)
  2. Login to Twitter/X in your browser
  3. Visit any Twitter profile page while logged in
  4. Click the extension icon → Export cookies as Netscape format
  5. Save as cookies.txt in project root: c:\Users\babapro\Downloads\reelsindirici\
